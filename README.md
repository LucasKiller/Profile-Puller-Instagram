# Profile Puller Instagram

## Descrição 📄

O **Profile Puller Instagram** é uma aplicação que permite obter informações detalhadas de insights de contas comerciais do Instagram. Com esta aplicação, você pode facilmente pegar o username do Instagram e puxar uma série de dados valiosos sobre a conta, como métricas de engajamento, alcance, impressões, e muito mais.

## Funcionalidades 💻

- **Autenticação do Usuário:** Permite que os usuários façam login com suas contas do Instagram.
- **Obtenção de Dados:** Recupera informações de insights das contas comerciais do Instagram.
- **Exibição de Métricas:** Exibe dados como alcance, impressões, engajamento, seguidores, entre outros.
- **Exportação de Dados:** Permite a exportação dos dados em formatos como CSV e PDF para análises posteriores. (FUTURAMENTE)

## Uso 📲

1. **Login:** O usuário deve fazer login com sua conta do Instagram para permitir o acesso aos dados de insights.
2. **Entrada do Username:** Após a autenticação, o usuário insere o nome de usuário do Instagram.
3. **Exibição de Insights:** A aplicação puxa e exibe os insights da conta comercial do usuário.
