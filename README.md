# Profile Puller Instagram

## Descrição 📄

O **Profile Puller Instagram** é uma aplicação que permite obter informações detalhadas de insights de contas comerciais do Instagram. Com esta aplicação, você pode facilmente vincular sua conta Facebook que está conectado o seu Instagram Business e puxar uma série de dados valiosos sobre a conta, como métricas de engajamento, alcance, impressões, e muito mais.

## Funcionalidades 💻

- **Autenticação do Usuário:** Permite que os usuários façam login apenas com sua conta do Facebook.
- **Obtenção de Dados:** Recupera informações de insights das contas comerciais do Instagram.
- **Exibição de Métricas:** Exibe dados como alcance, impressões, engajamento, seguidores, entre outros.
- **Exportação de Dados:** Permite a exportação dos dados em formatos como CSV e PDF para análises posteriores. (FUTURAMENTE)

## Uso 📲

1. **Login:** O usuário deve permitir ao **Profile Puller Instagram** que possa obter as informações da página conectada ao Instagram Business do perfil.
2. **Customização de informações:** Após a autenticação, será apresentado uma sequência de dados de insights os quais ele deseja exibir.
3. **Exibição de Insights:** A aplicação puxa e exibe os insights da conta comercial do usuário.
